# Personal Agent 0.3 — 我的个人桌面助手

这是一款面向日常咨询、学习、生活、编程和个人项目的 Windows 桌面助手。IAM 实验室是其中一个可选模块。
界面、聊天和记忆在本地；GPT-6 推理通过 OpenAI API 完成。它不是在本机部署 GPT-6 模型。

## 安装与开始

1. 将 `Personal-Agent-v0.3-Windows.zip` 完整解压，运行 `Personal-Agent.exe`。
2. 保留同目录中的 `_internal` 文件夹，无需另装 Python。
3. 在“设置”中填写自己的 OpenAI API key。需要账号能够访问 `gpt-6-astra`；没有权限时应用显示错误，不自动换模型。
4. 先在“个人空间”聊天。可修改助手的称呼。
5. 在“记忆”中保存个人偏好和重要背景，在“进行中的事”中记录目标、进度与下一步。

关闭窗口会收起到托盘；点击托盘图标或按 **Ctrl+Alt+Space** 唤出。托盘右键菜单或侧栏“退出助手”可彻底退出。
若快捷键被其他软件占用，会显示提示；仍可从托盘打开。
可在设置里选择登录 Windows 后启动到托盘，默认不启用。移动程序目录后，需要重新保存这个设置。

## 三个空间

| 空间 | 用途 | 外部模型 | 资料同步 |
|---|---|---|---|
| 个人 | 生活、学习、兴趣、一般咨询 | 预览后发送 | 逐条明确发布 |
| 实验 | 模拟环境、代码、IAM 实验 | 预览后发送 | 逐条明确发布 |
| 工作 | 不能外传的工作记录 | 禁止 | 禁止 |

空间之间不会自动混用记忆。工作空间可以保存本地对话笔记、任务和记忆，但无法使用云端 AI 分析这些内容。
把工作内容粘贴到个人或实验空间并不会使其变成可外发资料；应用无法自动判断内容归属，请按公司的要求使用。

## 连续对话与长期记忆

- 普通聊天自动保存，重新打开应用后可以继续；草稿每 5 秒及切换页面时保存。
- 当前对话附带最近最多 24 条、合计不超过 20,000 字符的历史。更早的完整聊天仍保存在本地，发送预览会说明省略数量。
- 本地检索会选择当前空间中的相关记忆、固定背景、进行中的任务和过往对话片段，合计不超过约 8,000 字符。
- 检索使用本地关键词与中文词片段匹配，不使用外部嵌入服务。它不是全量读取多年聊天，也不能保证每次都找到所有相关内容。
- 在新对话说“继续上次的话题”，会提供最近相关话题供模型理解；有歧义时应澄清。
- 输入 `记住：我更喜欢先看结论，再看解释`，会打开可编辑的记忆表单，保存后才成为长期记忆。
- 每条记忆带来源、更新时间、状态。只有当前空间中已确认、允许用于 AI、没有冲突的记忆才参与自动检索。
- 标记“固定背景”用于语言、回答习惯等常用信息。标记“待核实”或“已过时”的记忆不参与自动检索。
- 普通对话仍可被作为历史片段检索；若不想留下记录，请使用“临时对话”。

“临时对话”不保存消息和草稿，也不读取长期记忆。退出应用、切换到其他普通对话或新建临时对话会丢弃其会话内容。
临时对话仍会调用 OpenAI API；它不等于云服务的零保留模式。

“删除 / 忘记”会移除该记忆的本地历史版本，阻止其继续作为记忆检索。
如果原始聊天中仍包含相同内容，需另行删除对应对话。同步服务的历史版本、回收站和外部备份需单独管理。
删除是应用层面的逻辑删除与数据库清理，不是对存储介质的安全擦除承诺。

## 两台电脑使用

两台电脑分别解压运行，各自保存本地数据库。不要直接用云盘同步正在使用的 SQLite 数据库。

1. 准备两台电脑都可访问的资料交换目录。可以是已有同步软件管理的文件夹，或手工拷贝的文件夹。
2. 分别在设置中填写这个目录在本机的路径。
3. 在记忆、任务或聊天中选择“发布”，检查全部内容后确认。
4. 另一台电脑点击“同步已发布资料”，或者开启每 30 秒检查。实际跨设备传输由你的同步软件完成。
5. 收到的记忆需打开检查，勾选“允许作为 AI 上下文”后保存；不会仅因为来自同步目录就自动信任。

每次发布只包含当前审阅的版本；后续编辑或新聊天消息需要再次发布。开启定时同步不会自动发布新的个人内容。
交换文件为明文 `.agent.json`，只包含发布记录及版本信息。没有内置云账号、远程执行或服务器。
两台电脑同时编辑同一记录时显示版本冲突，合并后再保存；冲突版本不会自动用于记忆回答。
删除已发布记录会在下次同步传播。即使旧电脑稍后上传旧版本，也不会使被删除的记录复活。

## 密钥与本地数据

- 默认 API key 只保存在当前进程内存中。
- 可选 Windows DPAPI 加密保存，绑定此 Windows 用户；不能把密钥文件复制到另一台电脑直接使用。
- 如果当前账户的 Windows 加密服务不可用，取消勾选加密保存，仍可仅在本次运行中使用。不会退回明文保存。
- 聊天和记忆数据库本身是本地明文，当前版本没有应用登录锁或数据库全盘加密。
- 本地数据目录：`%LOCALAPPDATA%\PersonalAgent`。**不要同步整个目录**，其中可能包含工作资料。
- 每次调用前展示本次对话与检索背景。`store: false` 不等于模型离线运行，也不等于对 API 数据零保留的承诺。
- 应用不持续记录屏幕、不读取所有文件、不自动执行模型输出的代码、不自动发送邮件或消息。

## IAM 与文件工具

实验空间保留 VirtualBox 列表、启动、正常关机、快照和 SSH 只读盘点；只在 VM 所在电脑启用执行。
目前基线是 Ubuntu 22.04.5 LTS、Tomcat 9.0.108、PingAM / AM 7.2.1，来自用户提供，尚未连接验证。
AM 重建清单可保存为任务。实际重建命令仍需确认 JDK、路径、目录服务及数据保留范围后实现。
文件工具支持第一层文件分类预览、移动及恢复，不自动上传文件内容。聊天可手动加入小型 UTF-8 文本文件。

## 从 IAM Workbench 0.1 迁移

旧版程序和数据不受修改。新版使用独立数据目录。
在“同步中心”选择“导入 v0.1 实验笔记”，指定旧版 `lab` 文件夹或实验交换文件夹。
只导入实验记录，标记为待核实；不会导入旧版工作区或私钥。导入操作不要对同一批文件重复执行，以免创建重复记忆。

## 当前边界

这是一版可测试的个人助手，不是无人值守的通用电脑操作 agent。
当前不提供语音、屏幕理解、网页搜索、定时提醒执行、自动记忆提炼或外部应用连接。
对话中的实时新闻、天气等不能保证最新；本版没有联网检索工具。
任务记录用于恢复进度，不会因为你写了截止时间就自动安排系统提醒。
没有用真实 API key 或真实 VM 验证；本地自动测试使用模拟 API 响应。

## 源码与测试

Python 3.12+（含 tkinter），运行托盘功能另需 `pystray==0.19.5`、`Pillow==12.3.0`。

```powershell
python -m pip install -r requirements.txt
python app.py
python -m unittest discover -s . -p "test_*.py"
python app.py --smoke-test
```

打包：

```powershell
python -m PyInstaller --windowed --onedir --hidden-import pystray._win32 --exclude-module numpy --name Personal-Agent app.py
```

已打包程序支持 `--smoke-test`：在临时目录检查三个空间的页面，不发起 API 请求、不连接 VM、不启用托盘或开机启动。
`--desktop-test` 会短暂创建托盘图标并注册快捷键，检查后退出并清理，仅使用临时数据目录。
DPAPI 在当前受限测试账户不可用，相应真实加密往返测试会明确跳过；默认的内存密钥模式不依赖它。
Windows 程序未进行代码签名。

参考：[OpenAI 会话状态](https://developers.openai.com/api/docs/guides/conversation-state)、[pystray Windows 用法](https://pystray.readthedocs.io/en/latest/usage.html)。

## 界面语言 / Interface language

在“设置 → 界面语言”中选择 English，然后点击“保存设置”，即可立即切换为英文。可随时切回简体中文，重启后保留选择。两台电脑分别保存语言偏好。

Choose **Settings → Interface language → English → Save settings**. The interface changes immediately and remembers your choice after restarting. Each computer keeps its own language preference. Existing chat, memory, task content and custom assistant names stay unchanged. This setting does not change the AI reply language. Native Windows file dialogs follow your Windows language.

升级：退出旧版，将新版解压到独立文件夹运行；继续使用原来的本地数据，不需要迁移记忆。
